# CALEON by Atlanticit — demonstração

Site estático, sem build. Funciona na Vercel (`vercel.json`), na Netlify (`netlify.toml`) ou em qualquer hospedagem estática.
Vercel: dentro desta pasta, execute `npx vercel --prod`.
A página inicial abre `Landing.dc.html`, com "Entrar" para o login.

Contas de demonstração (palavra-passe `demo2026`):

Após o login, um formulário curto permite indicar o nome da empresa e do responsável; os dados ficam só no navegador.
Dados fictícios; ligação à faturação em sandbox simulado; mapa esquemático. Requer internet (React e tipo de letra via CDN).
